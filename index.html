Sin costo inicial

Lanza tu MVP o portafolio sin inversión. Ideal para aprender y validar ideas antes de escalar.

Frontend & Serverless

Vercel

  • Deploy automático al hacer push a GitHub
  • Framework Detection: Next.js, React, Vue, Svelte, Astro
  • Serverless Functions (Node.js, Python, Go)
  • Analytics integrado
  • Preview deployments para cada PR
  • CDN global con Edge Functions
Ideal para: Frontend moderno + APIs ligeras

Hobby (Gratis)

  • 100 GB de bandwidth
  • Serverless: 100 GB-hrs
  • 1 persona, no comercial

Pro ($20/mes)

  • 1 TB de bandwidth
  • 1,000 GB-hrs serverless
  • Comercial permitido
Static Sites & JAMstack

Netlify

  • Deploy automático + drag & drop
  • Forms backend sin server
  • Functions (Lambda-based)
  • Split testing (A/B) integrado
  • Identity (auth básico incluido)
  • Redirects y headers desde archivo
Ideal para: Landing pages, portfolios, blogs estáticos

Starter (Gratis)

  • 100 GB de bandwidth
  • 300 minutos de build
  • 1 miembro del equipo

Pro ($19/mes)

  • 1 TB de bandwidth
  • 25,000 minutos build
  • Soporte prioritario

Resumen

Deploy gratis,
aprende deployando.

1

Empieza por Vercel o Netlify si tu app es frontend. Es lo más rápido para tener algo online.

2

Render para backend. Si necesitas API + DB, Render te da todo gratis con mínima config.

3

Oracle Cloud para el valiente. Si quieres un servidor real y no te asusta SSH, es el mejor deal que existe.

La mejor forma de aprender es haciendo.
